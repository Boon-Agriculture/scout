# Scout brand

Brand files for **Scout by Boon Agriculture**, built from QField (GPL-2.0-or-later, (c) OPENGIS.ch and contributors).

| File | What it sets |
|---|---|
| `brand.env` | App name, Android application id, default server |
| `theme.json` | App colours (same structure as `resources/theme/theme.json`) |
| `icon/qfield_logo.svg` | Logo shown inside the app |
| `icon/android/drawable/` | Android launcher icon (adaptive), splash and notification icon |

Colours: indigo `#1E2742`, terracotta `#B5531F`, straw `#E8C87E`, warm paper `#F5F1E8`.
